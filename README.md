# Royal Home Furniture — Showroom & Gallery

A React + Vite + Three.js prospect demonstration built on the reusable interactive showroom framework.

## Run locally

```cmd
npm install
npm run check
npm run dev
```

Open the local URL printed by Vite (normally http://localhost:5173). Or double-click `START-ROYAL-HOME.bat`.

## Demonstration scope

- Full-screen landing page
- Interactive 3D furniture showroom
- Product gallery with category filters and search
- Product detail panel and WhatsApp contact action
- Responsive layout

The gallery and showroom contain illustrative procedural 3D category concepts, not confirmed Royal Home stock or exact replicas. Prices are intentionally hidden. Before public launch, replace concepts with approved business photographs, exact product names, specifications, prices and availability. Confirm the business contact details and brand assets with Royal Home.
